# Bloomberg Message

Bloomberg Message is the core messaging service within the Bloomberg Terminal ecosystem, enabling financial professionals to communicate securely through the Bloomberg IB (Instant Bloomberg) messaging system with compliance archiving and monitoring.

## APIs

- **Bloomberg IB (Instant Bloomberg)** - Primary secure messaging service for financial professionals
- **Bloomberg Email Gateway** - Gateway for communicating with non-Bloomberg contacts
